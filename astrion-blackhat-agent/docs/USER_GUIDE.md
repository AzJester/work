# User Guide

## Quick start

1. Open the site. No sign-in is presented or required.
2. Choose a synthetic pursuit or select **Create pursuit**.
3. Complete the opportunity profile.
4. Add customer, competitor, and market artifacts in **Evidence Room**.
5. Record plausible competitors and challenge assumptions in **Competitors**.
6. Select a facilitation lens in **Playbook Library**.
7. Run **Black Hat Session**.
8. Review, copy, or download the Markdown assessment in **Output Center**.
9. Use **Export workspace** to make a portable backup.

## Data controls

The application saves after every change. Data remains in the browser profile on the
current device. Private/incognito windows may discard it when closed.

- **Export workspace** downloads a JSON backup.
- **Import** replaces the in-memory workspace with a valid exported JSON file.
- **Reset demo** replaces the workspace with synthetic sample data.

Export before clearing browser storage or moving to another device.

## Recommended operating practice

- Do not treat hypotheses as facts.
- Give every consequential claim a recognizable source and confidence level.
- Separate public/synthetic data from controlled pursuit information.
- Assign owners and dates to validation gaps.
- Export a dated backup before major sessions.
