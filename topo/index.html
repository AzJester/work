        Printing to scale

        1. Pick pages on the map, then choose Download PDF or Print.
        2. In the print dialog choose Actual size or 100%. Do not use "Fit to page".
        3. Measure the kilometre scale bar on the sheet with a ruler. At 1:25,000 one kilometre is 40 mm; at 1:50,000 it is 20 mm.
        4. Neighbouring pages share an edge, so trimmed sheets join without overlap.

        Reading the grid

        Grid squares are 1 km. Read right, then up: take the grid line left of the point and estimate tenths across, then the line below it and estimate tenths up. Four digits name a 1 km square, six digits a 100 m square.

        The readout at the bottom left of the map shows how far grid north (GN) and magnetic north (MN) sit from true north at the centre of the view. Each printed sheet carries the same values and the conversion between compass and grid bearings.

        Devices

        Garmin: the KMZ is a Custom Map. Copy it to the Garmin/CustomMaps folder on the device or its memory card. Older units read at most 100 images across all custom maps; newer ones 500.

        ATAK: the MBTiles file is a tile set. Import it with Import Manager or copy it to atak/imagery, then pick it from the map layers.

        Privacy

        Everything runs in this browser. Map tiles and elevation come straight from their public hosts, and a place search sends the text you type to the OpenStreetMap Nominatim service. Picked pages and settings are stored in this browser only.
